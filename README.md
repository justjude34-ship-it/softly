# Softly

A gentle holding place for things you’re putting off. Nest is a trauma-informed companion for ADHD and CPTSD task paralysis.

- Live app: after Vercel deploy, open the production URL
- Install on Android: Chrome menu → Add to Home screen
- Data stays on your device (localStorage)
- Softly is a supportive companion, not therapy or crisis care
